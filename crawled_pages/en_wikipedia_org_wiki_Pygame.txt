It includes computer graphics and sound libraries designed to be used with the Python programming language . [ 7 ] History [ edit ] Pygame was originally written by Pete Shinners to replace PySDL after its development stalled. [ 2 ] [ 8 ] It has been a community project since 2000 [ 9 ] and is released under the free software GNU Lesser General Public License [ 5 ] (which "provides for Pygame to be distributed with open source and commercial software" [ 10 ] ). Development of version 2 [ edit ] Pygame version 2 was planned as "Pygame Reloaded" in 2009, but development and maintenance of Pygame completely stopped until the end of 2016 with version 1.9.1. After the release of version 1.9.5 in March 2019, development of a new version 2 was active on the roadmap. [ 11 ] Pygame 2.0 released on 28 October 2020, Pygame's 20th anniversary. [ 12 ] Features [ edit ] Pygame uses the Simple DirectMedia Layer (SDL) library, [ a ] with the intention of allowing real-time computer game development without the low-level mechanics of the C programming language and its derivatives. This is based on the assumption that the most expensive functions inside games can be abstracted from the game logic, making it possible to use a high-level programming language , such as Python, to structure the game. [ 5 ] Other features that SDL does have include vector math, collision detection , 2D sprite scene graph management, MIDI support, camera, pixel-array manipulation, transformations, filtering, advanced freetype font support, and drawing. [ 13 ] Applications using Pygame can run on Android phones and tablets with the use of Pygame Subset for Android (pgs4a). [ 14 ] Sound, vibration, keyboard, and accelerometer are supported on Android. [ 15 ] Community [ edit ] Following disagreements between former core developers and the repository owner, a fork known as pygame-ce (Community Edition) was created. [ 16 ] There is a regular competition, called PyWeek, to write games using Python (and usually but not necessarily, Pygame). [ 17 ] [ 18 ] [ 19 ] The community has created many tutorials for Pygame.
