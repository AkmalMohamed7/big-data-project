Kaypa ch'anta hamawt'aynin khipukama (kuriku nisqa) ñawiriy atiyta aswanta kallpachan huk hatun inrintasiyun nisqata llamk'achiyta off-side kamachi nisqawan. Python nisqaqa k'uchi kaqmi, q'upa-huñusqapas. Yanapakunmi achka kamachiq parariqmakunata, chaymanta taqisqa (aswantaqa prusidural), object-oriented hinaspa hunsiyunal kamachiqta. Sapa kuti "pilakunayuq" simi hina willasqa, tukuypaq kamachisqa library kasqanrayku. [ 1 ] [ 2 ] Guido van Rossum 1980 watakunap tukukuyninpi Python nisqapi llamk'ayta qallarirqan, ABC nisqap kamachina simip qatiqnin hina, ñawpaq kutitaq 1991 watapi Python 0.9.0 sutiwan lluqsichirqan. [ 3 ] Python 2.0 nisqa, 2000 watapi lluqsirqan, musuq ruwanakunata riqsichirqan, ahinataq lista hamut'ay, cycle-detecting q'upa huñuy, pukyu yupay, Unicode yanapakuypas. Python 3.0 nisqa, 2008 watapi lluqsisqa, hatun musuqchasqa karqan, ñawpaq layakunawan mana hunt'asqa qhipaman t'inkisqa. Python 2.7.18, 2020 watapi lluqsisqa, Python 2 wirsiyun nisqamata qhapa wirsiyun qhipa lluqsiyninmi karqan. [ 4 ] Python sapa kuti huk astawan riqsisqa kamachiq simikunahina rankikun.
