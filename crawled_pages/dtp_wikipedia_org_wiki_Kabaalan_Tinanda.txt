Poomitanan tagayo do kabaalan tinanda nopo nga' id somit boros tagayo ( Large Language Model, LLM ) toi konibaan dau, SOBOYO . Tongo somit diti pakayon id kikiit do ponguhup sasangai ( virtual assistant ) miagal Google Assistant om Siri . Okon nopo dii, mumu gumu nodi pomogunaan do kabaalan tinanda maya somit boros tagayo irad it ChatGPT om Gemini , ii tiitikid mamakai do soboyo GPT-3.5 toi GPT-4 don OpenAI, om somit Gemini don Google. [ 1 ] [ 2 ] Laguwagu [ simbanai | simbanai toud ] Kabaalan tinanda nopo nga' kipuun id goos do kikito dountokud ( computer vision ), om tantad dii mogikakawo do somit noworun miagal it somit pamotintong gumulapau ( multilayer perceptron, MLP ), pukot ravo sumulit ( recurrent neural network ), pukot ravo mikisus ( convolutional neural network ), om it woyowaal ponimban ( Transformer architecture ). Pongilaan taahom [ simbanai | simbanai toud ] Pongilaan taahom (deep learning) nopo nga' kawo do raan pamot mogilo nga' poingotul id koilihan mantad somit di mongingkogos kopoilaan sidgumu ( statistics ) kumaa somit di poin'gonop okon don nupi ( parameter-based ). [ 3 ] Somit sunsuri gumutinulid ( multilinear regression model ) id ngaan do apat osimban. Sonsodo i tuku otulid montok tikid tapid do gatang y ^ {\displaystyle {\mathbf {\hat {y}}}} om x . {\displaystyle {\mathbf {x}}.} Lobi popoulinau pisuayan do pongilaan taahom om pongilaan toubas nopo kanou ontong poomitanan do somit di olosu', it somit sunsuritinulid ( linear regression models ) [ 3 ] : y ^ ⏟ somit = ∑ i d ( w i x i ) + b ⏟ garaid {\displaystyle \underbrace {\hat {y}} _{\text{somit}}=\sum _{i}^{d}(w_{i}x_{i})+\underbrace {b} _{\text{garaid}}} Om somit do pointodul id ngaan do d {\displaystyle d} nupi roitan do somit don nupi ( parameter-based model ). Hontol do pongilaan taahom nopo momorun do somit di kouyuyuo' nopo dau nga' okon pointodul togonop id gatang di tongo nupi dau. Pomogunaan id gana' pongotusan boros sandaudau [ simbanai | simbanai toud ] Pongotusan boros sandaudau, POROSAN ( natural language processing, NLP ) nopo raan id kabaalan tinanda poingotul id ponutunan do boros tulun id ogumu voos ugu tuturan ( speech ), ginait ( text ) toi ko' sinuat, om nogi gumukawo ( multimodal ) ii momorolot lobi iso voos do boros tulun. Poomitanan tagayo nopo id kabaalan tinanda dompomorun ( generative artificial intelligence ), ugu mamakai boros tulun kivoos ginait do mamabang kumaa it somit do popoulai timot ( image ) toi ko' guguyu ( video ).
