Linux ARM64 Download Download compatible with CentOS7 and later. Note SSL Certificates While the linux binaries ship an OpenSSL library, they do not ship a certificate store for SSL certificates. If you wish to use SSL module, you will need a valid certificate store. You can use the certifi package and set SSL_CERT_FILE to certifi.where() or install your platform certificates which should be discovered by the _ssl module.
