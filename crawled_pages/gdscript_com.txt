GDScript GDScript evolved as a custom scripting language to be used with the Godot computer (and mobile device) Game engine, and for those people who look beyond the real world, it also supports Virtual Reality. GDScript is easy to learn with a syntax similar to Python where the code is indented rather than using lots of brackets and semicolons. It allows for rapid code development and leverages the rich library of available functions within the Engine for fast enough speed of execution for the Game Logic in most cases.
