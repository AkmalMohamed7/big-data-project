'lopung') nopo nga' iso boros tokud topong akaas om kiguno poinggayo. Woyosorou pomotuan dau lobi monginsok do komilodoguan do hisok miampai ogumu ponginsiran ( indentation ). Winonsoi di Guido van Rossum o boros tokud diti di tulivot 80on id Centrum Wiskunde & Informatica (Longkod Simbakuro om Sidkopoilaan) id Nidolon. Python nopo nga' mongimuai-kawo dontuzat ( dynamically type-checking ) om momuhu-rinomos ( garbage collected ). Sokodungon nogi ogumu pamamaal ponokudan, poingampai donponuhuan ( procedural ), tanudkotos ( object-oriented ), om donpampos ( functional ). Kinilou om Woyosorou [ simbanai | simbanai toud ] Boros tokud nokomoi mamakai do pongimuayan kawo, om rinuhangan do pongintaban suku ( reference counting ) om iso pomuhu rinomos kopiuman-galung ( cycle-detecting garbage collector ) koponguludan do tandaman ( memory ). [ 1 ] Gunoon nogi di Python ponguyadan ngaran dontuzat ( dynamic name resolution ), i kopogisompuru do ngaran wayaan om osimban namot panau do nundar ( program ). Nogi, taranon di pomotuan dau piipiro sakadai ponokudan donpampos ( functional programming ) maya do koubasanan Lisp (iso kaagu boros tokud). Haro dau pampos filter (sarak), map (tondos), om reduce (kuriai); pangahagan rayat ( list comprehension ), wakid ( sets ), om pomoros pomorun ( generator expressions ). Nointigas o woyosorou lugu do boros tokud nokomoi id Zen of Python (PEP20) poingampai o tiilihan ( aphorisms ) poomitanan: Mogot olumis ko' oita. Mogot poindarampak ko' poingkinogos. Mogot ointigas ko' obolit. Mogot obolit ko' omungkang. Kitahang komilodoguan.
